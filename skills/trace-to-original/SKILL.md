# Trace to the original

Follow `rules/scope.mdc`. Answer in the user's language.

1. **Quote:** search the exact wording in quotation marks; find the earliest dated appearance; open the original speech, transcript, book or post. Check the words and the surrounding context match.
2. **Statistic:** find the study, dataset or agency report it comes from; check the number, the unit, the year, and what was actually measured.
3. **Image or video:** use a reverse image search the user can run (for example the search engine's own image search) or a public archive; find the earliest copy, its date, place and original caption. Note crops, edits, and recycled old media.
4. **Web page that changed or vanished:** check a public archive such as the Internet Archive's Wayback Machine (https://web.archive.org/) and give the snapshot date. Respect its rate limits; if it answers 429, wait and do not retry in a loop.
5. Report: the original (title, author or publisher, date, URL), what changed between the original and the version the user saw, and anything that could not be traced (mark UNVERIFIED).
